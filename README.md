# Aura — Modern Digital Studio Website

A clean and modern landing page for a digital studio built using HTML, CSS, and JavaScript.

## 🚀 Features

* Responsive design
* Smooth scrolling navigation
* Animated sections (fade-up effects)
* Contact form UI
* Clean and modern UI/UX

## 📂 Tech Stack

* HTML5
* CSS3
* JavaScript

## 📸 Preview

A stylish landing page with:

* Hero section
* About section
* Services section
* Contact form

## 🛠️ Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/aura-digital-studio-site.git
   ```

2. Open the folder:

   ```bash
   cd aura-digital-studio-site
   ```

3. Run the project:

   * Open `index.html` in your browser
